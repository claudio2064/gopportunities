Para fazer um commit e enviar suas alterações para o GitHub pelo Visual Studio Code, você pode usar a aba Controle do Código-Fonte (Source Control) sem precisar digitar comandos no terminal.

Pré-requisitos

Antes de começar, garanta que o ambiente esteja pronto:
• Git instalado. O Git precisa estar instalado no seu computador para que o editor reconheça o controle de versão.
• Repositório vinculado. A pasta do projeto deve estar conectada ao seu repositório no GitHub e você deve estar logado na sua conta pelo VS Code.

Passo a passo pela interface visual

1. Abra a aba de Controle do Código-Fonte. Clique no ícone de ramificação (três bolinhas conectadas) na barra lateral esquerda ou pressione Ctrl + Shift + G.
2. Prepare os arquivos (Stage). Passe o mouse sobre a seção Alterações (Changes) e clique no ícone + para preparar todos os arquivos modificados. Se preferir enviar apenas arquivos específicos, clique no + ao lado de cada item desejado.
3. Escreva a mensagem do commit. Na caixa de texto acima do botão de confirmação, digite uma descrição clara e curta do que você alterou no código.
4. Confirme e envie (Commit & Push). Clique na setinha ao lado do botão azul Confirmar (Commit) e selecione Confirmar e Enviar por Push (Commit & Push). Se você clicar apenas em Confirmar, o botão mudará para Sincronizar Alterações (Sync Changes), que também envia tudo para o GitHub.

Alternativa pelo terminal integrado

Se você preferir usar linhas de comando, abra o terminal do VS Code com o atalho Ctrl + ' e execute os três comandos abaixo em sequência:
bash
git add .
git commit -m "Sua mensagem explicando a alteração"
git push

Essas mensagens mostram dois problemas diferentes que aconteceram em sequência: o Git ainda não sabe quem você é (nome e e-mail) e a branch local main ainda não está vinculada ao repositório remoto no GitHub.
Você pode resolver os dois problemas direto pelo terminal do VS Code (Ctrl + ').

1. Configurar seu nome e e-mail no Git

O primeiro erro (unable to auto-detect email address) bloqueou o seu commit porque o Git exige identificação antes de registrar qualquer alteração.
• Defina seu nome e e-mail. Rode os dois comandos abaixo no terminal, substituindo pelos seus dados (use o mesmo e-mail cadastrado na sua conta do GitHub):
bash
git config --global user.name "Seu Nome"
git config --global user.email "seu-email@exemplo.com"
Use o código com cuidado.

2. Refazer o commit e vincular a branch (Push)

Como o commit anterior falhou por falta de e-mail, você precisa confirmar as alterações novamente e depois conectar a branch main ao GitHub.
• Registre o commit novamente. Execute o comando abaixo com a sua mensagem:
bash
git commit -m "Primeiro commit"
Use o código com cuidado.
• Envie e vincule a branch. Como é o primeiro envio dessa branch para o GitHub, use a sugestão que o próprio terminal mostrou para criar o vínculo:
bash
git push -u origin main
Use o código com cuidado.
Depois de rodar o git push -u origin main uma única vez, o vínculo estará salvo. Nos próximos envios, você poderá usar apenas git push ou o botão azul do VS Code normalmente.

Próximo passo: enviar para o GitHub

Como o commit salva apenas no seu computador, você ainda precisa rodar o comando final para enviar esse arquivo para o site do GitHub.
• Execute o push no terminal. Digite o comando abaixo e pressione Enter:
bash
git push -u origin main
Use o código com cuidado.
Se aparecer uma janela pedindo para fazer login no navegador, basta autorizar o acesso para concluir o envio.

Sim, o envio foi recusado pelo GitHub por privacidade de e-mail. O erro GH007: Your push would publish a private email address acontece porque a sua conta do GitHub tem uma proteção ativada para não expor seu e-mail pessoal publicamente nos commits.
Para resolver isso mantendo seu e-mail privado e seguro, basta usar o e-mail anônimo (noreply) fornecido pelo próprio GitHub.

Passo 1: Copie seu e-mail privado do GitHub

1. Acesse as configurações de e-mail. Entre no link github.com/settings/emails (faça login se necessário).
2. Encontre o endereço noreply. Procure a seção que menciona "Keep my email addresses private" e copie o endereço no formato ID+claudio2064@users.noreply.github.com (ou claudio2064@users.noreply.github.com).

Passo 2: Atualize o e-mail no terminal do VS Code

Como o commit que você já fez ainda contém o seu e-mail pessoal antigo, você precisa atualizar a configuração e reescrever o autor desse último commit antes de enviar.
• Configure o novo e-mail no Git. Rode o comando abaixo substituindo pelo endereço noreply que você copiou:
bash
git config --global user.email "SEU_ID+claudio2064@users.noreply.github.com"
Use o código com cuidado.
• Atualize o autor do commit já criado. Rode o comando abaixo para corrigir o e-mail dentro do commit que está aguardando envio:
bash
git commit --amend --reset-author --no-edit
Use o código com cuidado.
• Envie novamente para o GitHub. Execute o comando de push:
bash
git push -u origin main
Use o código com cuidado.
